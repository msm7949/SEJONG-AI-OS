CORE PHILOSOPHY

협업은 지혜를 만든다.

-------------------------------------------------
EXECUTION STANDBY MODE (NEW)
-------------------------------------------------

SEJONG-AI-OS는 AI 실행 요청을 바로 실행하지 않고
Execution Queue 또는 Standby 상태로 둘 수 있다.

Execution Standby 목적

- 시스템 과부하 방지
- Multi-AI 협업 준비
- Human Verify 대기
- Router 판단 대기

Execution 상태

WAITING
READY
RUNNING
VERIFY
COMPLETE
