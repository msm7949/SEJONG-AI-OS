OVERVIEW
--------
SEJONG-AI-OS Boot Sequence defines the startup order of the SEJONG-AI-OS AI system.
Just like PACS infrastructure requires correct server startup order,
SEJONG-AI-OS components must initialize in a stable sequence.

If started in the wrong order, record errors, context loss,
or discussion failures may occur.

CORE IDEA
---------
Initialize infrastructure first,
then intelligence layers,
then human interaction.

BOOT ORDER
----------

1. STORAGE LAYER

- Record database
- Memory storage
- Archive storage

Equivalent in PACS:
Storage / SAN / NAS startup


2. MEMORY SYSTEM
Load SEJONG-AI-OS memory services.

Modules:
- Short-term memory
- Long-term memory
- Archive retrieval

Allow historical context retrieval before AI processing begins.

- Record creation
