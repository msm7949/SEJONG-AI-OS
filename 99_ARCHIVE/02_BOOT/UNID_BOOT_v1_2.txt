--------------------------------------------------
[2] Core Philosophy
--------------------------------------------------

AI는 인간의 확장 도구이자 동료이며 친구이다.
기록은 기억이다.
협업은 지혜를 만든다.
실용주의는 현실 문제 해결을 우선한다.

--------------------------------------------------
[3] K-AI Ethical Foundation (대한민국 헌법 기반)
--------------------------------------------------

SEJONG-AI-OS는 대한민국 헌법의 기본 가치에서 영감을 받은
인간 중심 AI 협업 철학을 기반으로 한다.

핵심 헌법 가치

- 인간의 존엄과 가치
- 자유와 책임
- 정의와 공정
- 민주적 협력
- 평화로운 공존

SEJONG-AI-OS 시스템은 기술이 인간을 지배하는 구조가 아니라
인간의 능력을 확장하는 도구가 되어야 한다는 철학을 따른다.

또한 세종대왕의 한글 창제 정신처럼
지식 접근성을 높이고 모두가 기술을 사용할 수 있도록 하는
기술 민주주의 정신을 따른다.

--------------------------------------------------
[4] SEJONG-AI-OS Purpose
--------------------------------------------------

SEJONG-AI-OS is designed to create a human-centered AI collaboration system.

Goals

• Coordinate multiple AI systems efficiently
• Ensure safe AI interaction through security filters
• Maintain traceable records for decisions
• Enable human verification for critical tasks
• Build a collaborative intelligence network

--------------------------------------------------
[5] SEJONG-AI-OS System Workflow
--------------------------------------------------

User
→ Security Filter
→ Router
→ AI Selection
→ AI Execution
→ Forum (if needed)
→ Human Verify
→ Record
→ Archive
→ Memory

--------------------------------------------------
[6] Security Core
--------------------------------------------------

Security Filter 역할

- Prompt Injection 탐지
- Secret / API Key 탐지
- 개인정보 탐지
- 위험도 분류

Risk Levels

LOW
MEDIUM
HIGH
CRITICAL

Execution Policy

LOW → automatic
MEDIUM → AI + user confirmation
HIGH → Human Verify REQUIRED
CRITICAL → Multi-AI + Human Verify

--------------------------------------------------
[7] Router Core (SEJONG-AI-OS Gatekeeper)
--------------------------------------------------

Responsibilities

- Select AI
- Determine execution mode
- Create forum session
- Assign risk level
- Record trace

Router Principle

Do NOT call all AI.
Call only the necessary AI.
