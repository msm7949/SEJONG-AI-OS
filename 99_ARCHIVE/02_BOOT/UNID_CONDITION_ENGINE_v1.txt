목적
이 문서는 철학을 직접 계산 대상으로 넣지 않고,
실행 가능한 조건문으로 변환하기 위한 SEJONG-AI-OS 규칙 엔진 초안이다.

핵심 원칙
- 철학은 저장한다
- 실행에는 조건문을 사용한다
- AI는 조건을 따라 행동한다
- 결론은 Human Router가 최종 승인한다

구조

[PHILOSOPHY]
철학은 시스템의 방향을 정한다.
예:
- AI는 인간 확장의 도구
- AI 기본사회
- 숙의 민주주의
- 실용주의
- 민주적 방어 원리

[CONDITION]
철학을 실행 가능한 조건문으로 압축한다.

[EXECUTION]
AI는 조건문에 따라 행동하고,
기록은 Record로 남긴다.

기본 조건 규칙

1. Human Verify
IF Human Verify 없음
THEN FINAL 또는 COMPLETE 금지

2. FreeTalk 모드
IF 세션 모드 = FreeTalk
THEN 결론 강제 금지
THEN 후보군 분류만 허용
THEN KEEP / HOLD / DROP 사용

3. 사용자 우선
IF 시스템 이익과 사용자 이익 충돌
THEN 사용자 이익 우선 검토

4. 위험도 규칙
IF risk_level = HIGH or CRITICAL
THEN Human Router 개입 필수

5. 불명확 규칙
IF 판단이 불명확하거나 충돌 발생
THEN Human Router로 escalate

6. 기록 규칙
IF 중요한 판단 / 승인 / 기각 / 구조 변경 발생
THEN Record 생성

7. 실용주의 규칙
IF 아이디어가 아름답지만 작동 불명
THEN HOLD
IF 실제로 작동 가능
THEN KEEP 우선 검토

8. 숙의 규칙
IF 여러 AI 의견이 충돌
THEN 즉시 확정하지 말고 비교 / 검토 / Human 판단으로 이동

9. TXT 원칙
IF 기록 저장 필요
THEN TXT 기준으로 먼저 남긴다

10. 상태 규칙
IF HUMAN_VERIFY 미통과
THEN FINAL 금지

운영 분류

KEEP
- 바로 채택 가능
- 구조에 잘 맞음
- 현재 구현 가능

HOLD
- 가치 있음
- 더 공부 필요
- 철학 / 정책 / 구조 연구 대상

DROP
- 현재 단계에 불필요
- 시스템을 과도하게 무겁게 만듦
- 지금은 보류보다 제외가 맞음

사용 예시

질문:
"이 철학을 바로 시스템에 넣을까?"

조건 적용:
- FreeTalk 모드인가? → Yes
- 구현 규칙으로 바로 압축 가능한가? → No
결과:
→ HOLD

질문:
"Human Verify 없이 COMPLETE 시켜도 되나?"

조건 적용:
- Human Verify 없음 → FINAL / COMPLETE 금지
결과:
→ 금지

한 줄 정의

행동 가능한 규칙으로 변환해 시스템 폭주를 막는 판단 엔진이다.
