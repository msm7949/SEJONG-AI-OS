SEJONG OS N8N AUTOMATION LINK v1

[System]
SYSTEM = SEJONG OS
MODULE = n8n Automation Link Design
HUMAN_ROUTER = HMN

[Purpose]
세종 OS의 ROUTER, TASK_QUEUE, RECORD 구조를
n8n 자동화 흐름과 연결하기 위한 설계 문서이다.

--------------------------------------------------
1. AUTOMATION GOAL
--------------------------------------------------

세종 OS 자동화의 목적은 다음과 같다.

- TASK 상태 변경 자동 추적
- WAIT_FOR_SYNC 전환 시 알림
- 승인 후 파일/기록 저장 자동화
- ARCHIVE 이동 흐름 지원
- Human Router 승인 지점을 명확히 유지

중요:
자동화는 보조 역할만 수행한다.
최종 결정은 반드시 HMN이 수행한다.

--------------------------------------------------
2. CORE CONNECTION MAP
--------------------------------------------------

INPUT
→ ROUTER
→ AI_FORUM
→ TASK_QUEUE
→ WAIT_FOR_SYNC
→ HMN 승인
→ RECORD 저장
→ ARCHIVE 이동
→ 필요 시 외부 서비스 반영

--------------------------------------------------
3. N8N FLOW DESIGN
--------------------------------------------------

FLOW A. TASK 생성 감지
- Trigger: 새 TASK 생성
- Action 1: TASK 상태 = REQUESTED 확인
- Action 2: 담당 AI / 문서 / 우선순위 기록
- Action 3: 알림 또는 로그 저장

FLOW B. WAIT_FOR_SYNC 알림
- Trigger: TASK 상태가 WAIT_FOR_SYNC로 변경
- Action 1: HMN에게 승인 대기 알림
- Action 2: 관련 문서 링크 첨부
- Action 3: 자동 승인 금지 유지

FLOW C. APPROVED 이후 실행
- Trigger: HMN 승인 입력
- Action 1: TASK 상태를 APPROVED로 업데이트
- Action 2: IN_PROGRESS 전환 준비
- Action 3: 필요한 문서 생성/정리 자동화

FLOW D. DONE 이후 기록 저장
- Trigger: TASK 상태가 DONE
- Action 1: RECORD_TEMPLATE 기반 기록 생성
- Action 2: 파일명/버전명 표준 적용
- Action 3: ARCHIVE 필요 여부 확인

FLOW E. ARCHIVE 이동
- Trigger: archive_required = YES
- Action 1: 파일을 ARCHIVE 경로로 이동
- Action 2: ACTIVE / ARCHIVE 구분 유지
- Action 3: 이력 로그 저장

--------------------------------------------------
4. REQUIRED HUMAN CHECKPOINTS
--------------------------------------------------

자동화가 있어도 아래는 반드시 인간(HMN) 확인 필요:

- 민감 정보 처리
- 외부 공개 여부 결정
- 최종 승인
- 정책 충돌 판단
- 위험 신호(risk_flags) 존재 시

--------------------------------------------------
7. RULES
--------------------------------------------------

- WAIT_FOR_SYNC 상태에서는 자동 완료 금지
- APPROVED 없는 자동 배포 금지
- DEV 구조와 PROD 구조를 분리
- ARCHIVE 정책 위반 금지
- 모든 자동화 로그는 추적 가능해야 한다

--------------------------------------------------
8. ONE-LINE SUMMARY
--------------------------------------------------

n8n은 세종 OS의 작업 흐름을 보조 자동화할 수 있지만,
최종 통제와 승인 권한은 항상 Human Router(HMN)에게 있다.
