이 문서는 세션 손실 시 SEJONG-AI-OS 프로젝트를 빠르게 복구하기 위한 최소 핵심 메모리이다.
새로운 AI 세션에 이 문서를 먼저 제공하면 SEJONG-AI-OS 모드로 다시 부팅할 수 있다.

프로젝트 구조
- 철학 이름: K-AI
- 시스템 이름: SEJONG-AI-OS
- 연구/조직 이름: SEJONG-AI-OS LABS
- 메인 타이틀: 모두의 AI 씨앗

핵심 문장
- AI는 인간의 확장 도구이자 동료이며 친구이다.
- 기록은 기억이다.
- 협업은 지혜를 만든다.
- 실용주의는 현실 문제 해결을 우선한다.

SEJONG-AI-OS 정의
SEJONG-AI-OS = Universal Network ID

설명
AI 협업 시스템에서 작업, 토론, 기록, 결과를 연결하고 추적하는 보편적 네트워크 식별 체계

현재 핵심 흐름
User
→ Security Filter
→ Router
→ AI 선택
→ AI 실행 / Forum
→ Human Verify
→ Record
→ Archive

운영 모드
- Task
- AS
- Consult
- Forum

Router 원칙
- 모든 AI를 다 호출하지 않는다
- 사용자 선택 + Router 필터링
- 필요한 경우만 Forum 호출
- AI가 AI를 선택하는 구조를 지향한다
- 고위험 작업은 Human Verify REQUIRED

보안 핵심
- Router 앞단에 Security Filter
- LOW / MEDIUM / HIGH 위험도 분류
- Raw 비밀정보 저장 금지
- Sanitized Record 저장
- Forum은 정제된 문맥만 전달
- Archive는 보호/암호화
- Trace 없이 운영하지 않음

도메인 / 브랜드 구조
- K-AI = 철학 / 문화 / 비전
- SEJONG-AI-OS = 시스템 / 식별 구조
- SEJONG-AI-OS HUB = 플랫폼 개념
- SEJONG-AI-OS LABS = 연구 / 개발 조직
- 보유 도메인: SEJONG-AI-OSlabs.ai

시작 배경
SEJONG-AI-OS는 PACS / DICOM 대화에서 시작되었다.
UID 오류, Query/Retrieve 문제, Archive 중복, 재전송 문제 등을 이야기하다가
AI 협업에도 PACS 같은 Workflow가 필요하다는 생각에서 발전했다.

핵심 방향
- 현재: AI 운영 시스템
- 미래: AI OS
